# Stephanus 拉丁化 skill 设计稿

状态：接口已按 compact-v1 实现；本文件用于后续编写 skill，当前不安装 skill。

## 职责与调用边界

建议名称为 `stephanus-latinization`。用于为创作者提供日语姓名的拉丁语形式、语义转译、欧洲姓名借鉴和自由创作候选。直接复用七个只读 MCP 工具，不调用模型 API，不建立独立 Agent 调度器。

用户给定的读音、风格和候选数量优先；未指定时给出五个有区别的参考候选。允许改变意义、借用同音字意象或直接创作，简短交代采用的路线即可，不设置统一评分。

## 先摘要，后详情

- `stephanus_list_sources()`：只在需要了解覆盖和后端状态时调用；完整资源清单通过 `include_resources=true` 取得。
- `stephanus_search_names(query,language,category,source,mode,limit,offset)`：搜索写法、读音或释义。`extra.match` 表示实际匹配方式。
- `stephanus_lookup_words(...)`：日语和拉丁语词目查询；`source="verba",language="la",mode="meaning"` 优先匹配 Smith & Hall 英语词目。
- `stephanus_get_entry(identifier)`：取得保留的义项、词源、词形、相关词、历史资料和来源。原词典文章、用例全文和原始 JSON 已移除。
- `stephanus_find_related_names(identifier,relation,limit,offset)`：查现有变体、相似、文化对应和转写关系，沿用原关系类型。
- `stephanus_transliterate_name(text,scheme)`：复用 romkan，输入是假名或其支持的罗马字；汉字先查读音。
- `stephanus_analyze_latin(text,limit)`：调用 Whitaker/verba 分析已有词形；不是完整的名称生成或变格接口。

列表的 `description` 最多 240 字。详情的 `extra.knowledge` 提供：

| 字段 | 内容 |
|---|---|
| senses | 义项、必要标签和适用写法/读音；Smith & Hall 可含 latin_equivalents |
| etymology | 词源说明，缺失时为空 |
| forms | 词形与语法标签，不含重复的整份词条 |
| related_words | 派生、近义、跨语言词汇联系 |
| attestations | 已保留的姓名年代、地区和文献定位 |
| lemma_links | 纯词形或异体对应的词目文字、语言、标签及已找到的条目 ID |

来源由 `extra.provenance` 提供。别名所指词目不明确时，返回原目标文字，不据此假定唯一词源。

## 转换路线

1. **语音路线：** 查日语姓名读音，调用罗马字工具，再由 Agent 选择词干和拉丁语形式。用户未指定读音时可并列展示不同假设。
2. **同音意象路线：** 按假名查其他写法，选择有用意象；说明借用了新写法的字义。
3. **语义路线：** 整体词义优先；整体不成词时查所需汉字。选取明确的英语概念，查询英拉词库，再读取拉丁语义项或词源。
4. **既有姓名路线：** 查已有欧洲姓名及关系，根据语言、历史形式和词源选取或改写；相似和文化对应不直接解释成同源。
5. **自由创作路线：** 现有资料不足时，根据读音、意象和风格直接创作。需要词形参考时调用分析工具，不强求每个造名都能被词典识别。

默认不把每条路线都穷尽。候选比较由 Agent 组织为名称、读音或形式、所走路线、简短含义及关键参考。历史拼写只有已读资料支持时称为实录；风格加工简短标注为推导或创作。

## 四类调用示例

**汉字姓名「早苗」：** 查姓名写法及读音；按选定读音查同音写法；查整体词义或「早」「苗」字义；以其中一个英语意象查 verba；只对实际选中的词目取详情。

**假名输入「しんじ」：** 按读音查姓名写法，调用 Hepburn 得到罗马字；可并行采用语音加工与选字语义路线。罗马字转换结果本身不称为历史拉丁语实录。

**已有欧洲姓名「John」：** 查询 Onomaverse 或 Medieval，读取变体关系；根据用户风格选取对应形式。`und` 表示未确定语言，不能直接当成拉丁语。

**无直接对应的自造名字：** 尝试读音或局部意象；无合适词目时继续创作，不让空检索阻断任务。输出中指出加工部分，并保留实际使用的少量条目 ID。

## 后续 skill 的组织

入口仅放职责、七个工具的使用要点和路线选择；字段说明及这些示例作为按需读取的参考。历史转写参考沿用本项目保留的小型资料，不复制整套词典，也不将本轮数据处理流程写进创作者使用流程。
