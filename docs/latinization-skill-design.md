# Stephanus 拉丁化 skill 设计稿

修订日期：2026-11-11。状态：按 [Issue #1](https://github.com/hikjesen/Project-Stephanus/issues/1) 修订，用户已暂时通过并授权以「若叶睦」实践；用于后续编写 skill，当前不安装 skill。四类方法的参考指引见下表。

## 职责与调用边界

建议名称为 `stephanus-latinization`。用于为创作者将日语姓名转成拉丁语形式、历史欧洲转写或自然的欧洲姓名别名。数据库提供材料，skill 提供方法与参考，Agent 选择、推导和组合候选。直接复用七个只读 MCP 工具，不调用模型 API，不建立独立 Agent 调度器。

用户给定的读音、目标语言或地区、时代风格、候选数量优先。未指定时，优先探索在目标文化中自然、有既有姓名或命名惯例参照、与原名保持间接联系的形式；允许明显改变声音、拼写和意义。通常给出三至五个来源路径有区别的候选，不为凑数穷尽方法。

“拉丁化”在这里涵盖数种创作目标。历史日语转写、可用于拉丁语的姓名形式、现代罗曼语族姓名分别标明；按用户偏好选择，不把三者当成同一种成品。用户明确要求强保音、逐义翻译或自由造名时，按该偏好调整。

## 暂定选择原则

- 先确认姓名的写法、读音和姓／名。完整姓名未命中时拆分查询；人物读音结合用户或官方资料选择，未确定时简短说明采用的读音假设。
- 从用户希望的声音辨识度、含义或人物意象、表面差异、地区与时代风格中选择重点，不要求用户先选方法编号，也不设置量化权重。
- 默认优先探索真实姓名及有参照的历史方法。查到普通词后，继续考虑可用作姓名的整体形式、已有姓名和相关变体；初步检索不理想时，可换概念或方法，无需穷尽资料。
- 默认不将日语姓名逐字翻译后强拼成拉丁短语。可以保留主要意象、使用间接联系或舍弃部分字义；词义与语法可解释，不等于已经获得自然姓名。
- 姓与名独立推演，再按目标命名风格组合。允许一部分保音、另一部分取意，也允许保留或弱化原姓、采用单名。避免整组候选仅替换名字而复用同一创作姓氏。
- 自由创作保留为扩展方法：用户偏好或命名效果适合时可直接采用；默认先探索上述材料。创作部分简短注明，不要求每个候选都有历史实录。

## 先摘要，后详情

- `stephanus_list_sources()`：只在需要了解覆盖和后端状态时调用；完整资源清单通过 `include_resources=true` 取得。
- `stephanus_search_names(query,language,category,source,mode,limit,offset)`：搜索写法、读音或释义。`extra.match` 表示实际匹配方式。
- `stephanus_lookup_words(...)`：日语和拉丁语词目查询；`source="verba",language="la",mode="meaning"` 优先匹配 Smith & Hall 英语词目。
- `stephanus_get_entry(identifier)`：取得保留的义项、词源、词形、相关词、历史资料和来源。原词典文章、用例全文和原始 JSON 已移除。
- `stephanus_find_related_names(identifier,relation,limit,offset)`：查现有变体、相似、文化对应和转写关系，沿用原关系类型。
- `stephanus_transliterate_name(text,scheme)`：复用 romkan，输入是假名或其支持的罗马字；汉字先查读音。
- `stephanus_analyze_latin(text,limit)`：调用 Whitaker/verba 分析已有词形；不是完整的名称生成或变格接口。

罗马字工具目前支持 Hepburn、训令式及假名转换；历史语音转写需另读方法 A 的参考。词形分析仅提供词目和语法线索，姓名使用情况及历史规则另由条目或文献支持。

列表的 `description` 最多 240 字。详情的 `extra.knowledge` 提供：

| 字段 | 内容 |
|---|---|
| senses | 义项、必要标签和适用写法/读音；Smith & Hall 可含 latin_equivalents |
| etymology | 词源说明，缺失时为空 |
| forms | 词形与语法标签，不含重复的整份词条 |
| related_words | 派生、近义、跨语言词汇联系 |
| attestations | 已保留的姓名年代、地区和文献定位 |
| lemma_links | 纯词形或异体对应的词目文字、语言、标签及已找到的条目 ID |

来源由 `extra.provenance` 提供。别名所指词目不明确时，返回原目标文字，不据此假定唯一词源。

## 四类核心方法与按需参考

这些是可选择、可组合的方法，不要求每次平均生成四类结果。确认用户偏好后，只加载实际使用的方法参考。

| 方法 | 适用意图与输入 | Agent 的主要动作 | 按需读取 |
|---|---|---|---|
| A. 历史语音转写 | 保留日语声音，采用特定历史欧洲拼写 | 查已知读音及历史文献；选定文献／时代传统后转写，区分实录和类推 | [历史日语转写](references/historical-japanese-transliteration.md) |
| B. 传统形态拉丁化 | 保留音形，同时获得可解释的拉丁语名形 | 先查已有拉丁形式，再参照外来人名拉丁化的词干、词尾惯例；必要时分析词形 | [人名形态拉丁化](references/personal-name-latinization.md) |
| C. 人文主义语义拉丁化 | 允许明显改名，保留整体含义或主要意象 | 参考语义改名实例，寻找适合作为姓名的整体形式；允许局部保义与间接意象 | [人文主义语义拉丁化](references/semantic-humanist-latinization.md) |
| D. 拉丁词源与概念 → 既有欧洲姓名 | 优先自然的欧洲姓名、历史变体或罗曼语族形式 | 从词汇提出姓名线索，查询已有姓名及其词源、语言和历史记录，再选取变体 | [欧洲姓名与罗曼语族检索](references/romance-onomastics.md) |

A 可为 B 提供历史拼写材料；C 可为 D 提供语义入口。采用罗曼语族现成姓名时标明实际语言；历史转写未明显改变外观也可以有用，不强行把每种方法都加工成同样风格。

### 同音借义与自由创作

同音异字是辅助入口：按假名找其他写法，选取新意象，再连接 C、D 或自由创作。例如「さなえ → 佐名恵 → 恵 → grace → Gratia」借用了新选字的含义；不将其覆盖为「早苗」的原义。

自由创作可基于声音、词根或人物意象，但避免把普通词加上 `-a`、`-us` 就默认判为自然人名。若采用这种加工，说明借鉴的构形或审美理由，并与有姓名使用依据的候选作有意义的区分。

## 从材料到候选

查询过程由实际结果决定：姓名解析 → 挑选方法及材料 → 寻找姓名／历史规则 → 组合并选择候选。整体词义优先于拆字；英语可作为查询英拉词库的桥梁，无需成为所有方法的必经语言。

由拉丁词汇转向姓名时，可先尝试词本身、已知姓名形式或词源线索，再对选中的姓名使用 `get_entry`、`find_related_names`。Onomaverse 主要提供写法与关系，不能假定它能按词义查到全部人名；Medieval 的词源、年代、地区资料及按需外部参考可补充。关系类型为相似、文化对应或转写时，按原类型解释。

每个候选简洁给出：**姓名（名／姓结构）｜语言或风格、方法｜关键形成链与依据**。形成链可以是「原义或同音借义 → 词汇／姓名线索 → 既有姓名或历史规则 → 本次组合」。实际使用的少量 entry ID、文献页码或链接即可；原义、词源联系、意象借鉴、规则类推和创作加工在相关一步标明，无需逐项评分或长篇免责声明。

## 四类调用示例

**汉字姓名「早苗」：** 确认读音与整体词义后，按用户希望选择 A／B 或 C／D；在新芽意象和拉丁词汇之后继续探索真实姓名。姓氏另作选择，不默认复用直译短语。既有调用及其问题见 [案例与设计复盘](examples/kochiya-sanae.md#设计复盘2026-11-11)。

**假名输入「しんじ」：** 查读音对应的姓名写法；希望历史拼写时读 A，希望拉丁语名形时读 B，同音字义还可连接 C／D。现代 Hepburn 可作基线。

**已有欧洲姓名「John」：** 以 D 查询 Onomaverse 或 Medieval 的变体、词源和记录，根据语言与风格选取。`und` 表示未确定语言；规范名和文献中的实录写法分别读取。

**无直接对应的自造名字：** 以声音、局部意象或命名惯例寻找入口；材料仍不适合时自由创作，不让空检索阻断任务，也不强求完整保义。

## 后续 skill 的组织

后续 `SKILL.md` 的触发范围为日语姓名的历史转写、拉丁化及欧洲姓名别名创作。入口只保留目标、方法选择、工具要点、四份参考的加载条件及最小输出结构；不复制词库，不创建额外调度器或翻译服务。

本次参考复用本地历史资料与数据库，补充少量可定位的外部来源。历史规则暂以文字指引表达；机器可读规则表仅在后续实际使用需要时增加。保持 compact-v1 数据库与七个 MCP 工具。已有数据库验收及早苗调用记录沿用历史结果，不重跑、不改写为新方法已经通过。

按本暂定版本完成的实际调用见 [若叶睦案例](examples/wakaba-mutsumi.md)。它记录一次创作实践及方法选择，不将结果视为通用语言学准确性验收。
