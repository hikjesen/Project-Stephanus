# A. 历史日语转写

标准完整转译默认保留至少一条历史拼写特点类推路线；在意象选项之外告知，不让用户选择是否包含，也不占至少三个有效意象的数量。本路线主要依原读音与文献展开，无需受所选语义意象支配。整组至少一项回应用户选定，至少两项完整姓名从该意象之外的独立材料出发；本路线实际独立时可计其中一项，仍需另一条不同来源。现代罗马字作为读音基线，历史转写默认提供中间材料。

## 参考来源与适用范围

- Jaime González-Bolado，*Found in Transliteration: Japanese Names in Missionary Sources on Hideyoshi’s Invasions of Korea*，Japan Review 40（2025），213–240 页。[论文入口](https://doi.org/10.69307/japanreview.2025.Gonzalez-Bolado)；本地 `data/references/found-in-transliteration-jstage.pdf`。217–220 页讨论文献差异与拼写特点，附录用于找已有姓名／地名写法。研究对象主要为十六世纪末至十七世纪初相关传教士资料。
- 国立国语研究所，[罗马字表记为何有不同种类](https://kotoba.ninjal.ac.jp/qa/yokuaru/qa-183/)；本地 `data/references/ninjal-romanization.html`。用于了解现代体系的区别。
- 《日葡辞书》线索：本地 `data/references/nippo-jisho.html` 是目录入口。需要具体词形时，循入口查相应词条或文献，不将目录页视为词典全文。

## 怎样使用

先用 `search_names` 确认读音；需要时用 `transliterate_name` 得到现代基线。再按用户的时代风格查历史名字或相近音节的写法，保留具体文献传统；未指定时可采用上述传教士资料作为一种候选风格，简短注明。不要因为用户选择了语义意象而取消这条默认路线。

论文第 220 页列举的常见拼写特点，可作为人工类推的起点：

| 现代读音／写法线索 | 文献中的例子 | 使用提示 |
|---|---|---|
| `h` 与 `f` 的对应 | Hakata → Fakata | 先看该音节和文献环境 |
| `sh` 与 `x` 的对应 | Shimo → Ximo | 可用于识别该历史拼写风格 |
| `ts` 与 `c/ç` 的对应 | Tsushima → Çuxima | 结合该文献的其他拼写特点选用 |
| `k` 在 `a/o/u` 前的写法 | 文献用 `c` 表示相应音 | 不扩展为对所有 `k` 的替换 |

这些特点在文献中存在变体，不组成一个统一的“耶稣会转换器”。以上历史例子用于说明参照方法；现代姓名应用相近规律所得的形式，标为“据某文献习惯类推”。其他音节需要时再查原文，不为制造差异叠加未经参考的字母变化。

按姓、名分别使用适用的拼写特点，再组合完整候选；某部分没有适用变化时可沿用读音基线。历史文献中还可能含头衔、敬称与当时读音，选取时识别其成分；创作别名无需照搬头衔。仅在另一条语义候选的姓氏上借用一个拼写特点，不能替代独立的历史路线。

## 第二阶段：进入目标语言的姓名习惯

历史类推后，读取 [目标语言姓名适配](target-language-name-adaptation.md)，按本条采用的拉丁语或某种罗曼语族风格，继续寻找较生僻的音近姓名或有参照的构形方式。保留部分声音或节奏，允许缩减、重组及较明显改形；无需把这个名字的含义解释成用户为另一条路线选定的意象。

Muçumi Wacaba 完成的是历史拼写特点类推。后续应说明以哪些同语言的名／姓为参照，以及怎样加工为最终名字；不能只恢复现代拼写或再替换几个字母就结束。若目标是意大利语姓名，不将葡萄牙语式拼写本身当作意大利语姓名自然性的依据。

## 最小说明

保留「输入读音 → 文献／拼写特点 → 历史实录或类推中间形 → 目标语言姓名参照与加工 → 完整基础姓名」。完成后可另做可选修饰，同时给出修饰前后的完整姓名，仍计一个候选。用户明确只要历史转写时可以在中间形结束；创作目标语言别名时继续第二阶段。
