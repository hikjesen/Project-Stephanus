## 简短形成链与依据

1. **Cominia Amandine → Cominia Amandelia。** Komeiji → 有限历史拼写 Comeiji → 实际拉丁女性名形 Cominia；感情意象 → Amanda 词源系列 → 用户认可的具体变体 Amandine。Amanda 只作查询入口，不作为这次基础成品。可选修饰保留 Amand-，参照 Cornelia 一类名形的 -elia 收束，采用本次加工 Amandelia；这不是固定历史派生规则。依据：本地 medieval-names:app_variations.csv:1640、medieval-names:app_name_data.csv:1537，[DMNES](https://dmnes.org/name/Amanda)及 [Cominia Tyche 姓名实录](https://www.metmuseum.org/art/collection/search/253569)。

2. **Coixi Comeiji → Cosima Comini。** 原西式顺序 Koishi Komeiji，参考[历史指引](historical-japanese-transliteration.md)中 o 前 k → c、sh → x，得到有限类推中间形。随后以实际姓名 Cosima、姓氏 Comini 为参照，缩减元音串并重排部分声音，形成意大利语完整姓名。适配是创作借名，不是历史字母替换必然生成成品。本地 onomaverse:cosima-fn 有女性及意大利使用信息；[意大利文化部档案目录](https://inventari-san.cultura.gov.it/inventari/1559/pdf)列 Comini 的实际姓名。中间形不计成品，本条也没有额外修饰。

3. **Petrilla Claramontia。** こいし → 小石 → petra 石头词根，参照 Prisca → Priscilla 的指小名形，采用创作形 Petrilla；原姓“明、地”的视觉线索放宽为明亮山地，参照已有拉丁化姓氏 Claramontius 类推 Claramontia。两部分以本次创作身份给出，不声称取得其女性姓名实录。依据：verba:ls:petra#n1，[Priscilla 构形](https://dmnes.org/name/Priscilla)、[Claramontius 记录](https://www.deutsche-biographie.de/11765972X.html)。

4. **Candidella Celati。** 坦诚、澄明 → candidus → 选用已记录的历史变体 Candidella；闭合与隐匿的心 → celatus 的文学联想 → 借用真实姓氏 Celati。这里不声称 celatus 就是该姓的历史词源。依据：medieval-names:app_variations.csv:4520、verba:sh:5014，[Candidella 的主格记录](https://dmnes.org/name/Candida)、[Gianni Celati 的姓氏用法](https://www.treccani.it/enciclopedia/gianni-celati/)。

## 本例改变了哪些决定

- 从已认可的意象发展至少一条完整路线，同时至少两条完整路线从该意象之外的独立材料展开；历史声音默认保留，不参与意象投票。
- 基础选材已偏向有辨识度的形式；Amandine 的用户认可不等于对其全球稀有度作统计判断。
- 历史转写后必须进入目标姓名习惯；完成这一步后，后续修饰仍然可选。
- 原案例曾有单名 Candida、Amata 的提案，仍作为历史记录保留；当前每组只能额外选零个或一个有明确象征含义的单人名，不能同时附上两项，也不能补足完整姓名数量。
- 完整姓名至少四个，没有固定上限；有更多不同构造价值时继续追加，不要求每种方法各占一项。不把有依据的创作伪装成历史成品，也不以数据库空命中阻断创作。

## 反例：同一意象的三种包装

正冈子规测试中，“不屈的创造者”“渴望与坚韧”“承受锻造而成形”三个方向都从用户选定的“克服痛苦的创作欲望”推导，再加一个独立历史姓名。即使它们分别采用拉丁语、意大利语和法语，或使用不同隐喻，仍只有一个意象之外的构造起点，不满足至少两个独立完整候选的要求。

应在检索选名前就另安排一种原名材料来源；增加同一意象的同义变体不能补这个缺口。这里保留反例用于指导，未重做该测试的姓名或改写原始存档。
