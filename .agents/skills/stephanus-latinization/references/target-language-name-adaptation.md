# 共享指引：目标语言姓名适配

用于历史拼写类推后的第二阶段，以及需要自主构形的姓名创作。它衔接 A／B／D；四类方法与候选组的组织以[正式入口](../SKILL.md)为准。

## 区分用户意象与各条来源

沿用本条候选承担的原名材料，并确定目标为拉丁语名形，还是意大利语、法语、西班牙语等具体语言。倾向未明确时，提供至少三个有效的语义或人物意象选项；历史声音与拼写路线默认另行保留，不占选项。至少一条完整候选回应用户选择，至少两条完整候选从所选意象之外的独立材料出发；仅换语言、同义词或隐喻不算新来源。语言未确定时一并询问，已明确的偏好直接沿用。混合风格按用户允许的范围采用。

本步骤旨在创作适合目标语言使用的别名。历史转写所得词形提供联系线索；允许后续明显改形，不要求保留完整日语音节串。

## 用已有姓名指导加工

先在现有姓名库、历史条目或相关语言的资料中，寻找少量与中间音形或本条意象相关、用途相同的姓名，通常二至三个足以建立参照。名字参照名字，姓氏参照姓氏；同时看人物性别、用户选定时代和整体风格。

基础选材偏好生僻、有辨识度的名形；真实姓名不等于应优先取常见名。可从常见规范名的实录变体、地方写法、古雅形式或有依据的创作中选择。已有频率资料可辅助，未掌握精确统计时不宣称“全球罕见”，也无需为每个候选建立频率排名或统一门槛。先满足基础名的选材偏好，再考虑下面的可选修饰。

Agent 结合这些参照选择适合的处理：

- 有合适的音近现成姓名时直接借用，说明保留的声音或意象；音近联系不自动表述为词源关系。
- 需要创作时，从参照中判断音节节奏、重音、目标语言中的拼读方式，以及实际姓名的缩略、派生或复合模式；只采用与本次材料有关的特点。
- 可以缩短、重组或替换部分音节，保留用户看重的一处联系即可。仅改字母，或把原音节串加上某种语言常见后缀，不能单独说明姓名自然性。
- 名与姓分别加工后，结合目标语言的姓名组合选用。词汇形式、语法形式和姓名用法分别提供材料，整体效果由具体参照和用户风格判断。

每个自主创作候选简短说明「保留什么联系、参照什么姓名模式、改了什么」。参照是真实姓名，所得新组合或名形可以是本次创作；不要求所有新造形式已有收录，也不将参照模式说成日语到目标语言的既定音变规律。

## 可选的后续修饰

基础姓名已经完成目标语言适配与生僻偏好的选材后，可以再加工，以增强古雅感、音节节奏、辨识度或某种风格；这一过程不必对每条候选执行。

可选动作包括音节扩展、缩略、词尾重塑、参照既有名字的复合或派生构形。说明与参照相符的具体处理即可；修饰后的名字允许超出数据库原有词条，也不要求它已有完整历史实录。实际采用的是创作类推时据实标明。

有修饰时展示**完整基础姓名 → 完整修饰姓名**，两者作为同一候选的两个版本，仍只计为本组的一个候选；完整姓名以四个为下限，不设固定上限。例如先选用户认可的 Amandine，组合 Cominia Amandine，再按具体名形参照尝试 Cominia Amandelia；Amanda 只保留为这一词源系列的查询入口。Amandous、Amandino 等也可作为风格探索方向，不预设每种词尾都适用于所有语言与人物。

历史拼写后的适配与可选修饰分别处理：历史中间形 → 符合目标姓名习惯的基础名，是 A 路线的必要加工；基础名 → 进一步修饰，是可选加工。历史中间形不能充当已经选好的完整基础姓名。

## 可选的象征单人名

完整候选以外可额外给零个或一个无姓氏的单人名；不用为了覆盖这一类型而硬造。给出时写明它象征什么、从原名或人物的哪项材料形成，说明与目标风格的参照。只有省掉姓氏或音形好听不足以支持这个选项。它不计入至少四个完整姓名或至少两个独立完整候选；未提供时省略整段。

## 何时联网

本地条目足以支持当前选择时直接复用。需要判断某种名形是否用于目标语言、某项音形处理是否有参照，或模型只凭“听起来像”提出新名字时，再针对具体问题查姓名学资料、目标语言词典、论文或实际使用记录。

例如可查“目标语言＋候选／构形特点＋given name／surname／etymology”，或先查看上述专业资料中的姓名模式。记下实际使用的少量链接及其支持的判断即可；无需全语言爬取、强制评分或另建规则引擎。

## 形成链

「本条承担的联系 → 原读音／语义材料 → 历史类推中间形（若使用 A） → 目标语言中的姓名参照 → 音近借名或有依据的自主加工 → 较生僻的完整基础姓名 → 可选修饰后的完整姓名」。

Muçumi Wacaba 在这条链中属于中间材料。历史路线默认从声音材料继续加工，不占意象选项；与另一条不同来源的完整候选共同承担意象之外的探索，整组仍至少有一条回应该倾向。历史中间形不能占完整姓名名额。相关具体构造见[古明地恋成功案例摘要](worked-example.md)。
