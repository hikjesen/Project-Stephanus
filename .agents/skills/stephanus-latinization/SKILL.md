# Stephanus 名称转译

本项目的命名创作入口，供创作者将日语姓名转成拉丁语或罗曼语族风格的完整姓名。默认偏好生僻、有辨识度且有命名参照的形式；允许较大音形和意义变化、有依据的创作及跨风格组合。用户明确的语言、地区、时代和本次范围优先。

## 接入

优先调用本项目现有七个只读 MCP 工具。首次需要查询时读取[工具与运行指南](references/tool-usage.md)，按宿主实际暴露的工具名调用；MCP 未加载或连接不可用时复用已有 CLI。空命中不切换接口重查。

此 skill 目录向上三层是项目根目录。数据库 compact-v1、CLI 与 MCP 继续由原项目提供；欧洲姓名资料用于选材，首版完整转译流程面向日语原名。

## 一次命名

1. **解析输入。** 确认写法、假名读音和姓／名；完整姓名未命中时拆分，人物读音结合用户或可靠资料选择。汉字不直接交给罗马字工具。只有名字时，可补配创作姓氏并明示。

2. **交流倾向。** 先作少量输入查询，提供至少三个有材料支撑、可独立比较的语义或人物意象方向，简述各自联系与取舍，允许用户混合、否定或另提方向。历史声音与拼写路线默认保留，在选项之外说明，不让用户投票决定是否包含，也不占这三个有效意象的数量；语言、构造方法或同一意象的同义改写也不充当意象选项。材料不足时先补充必要资料。语言／风格未明确时一起询问；等待答复后再做依赖选择的检索和候选生成。已明确的意象直接沿用，不为凑选项重问；明确委托模型自选时可继续，沉默不是选择。

3. **分配路线。** 默认至少四个由姓与名构成的完整候选；四个只是下限，不设固定上限，有新增构造价值时继续增加。至少一个明确回应用户选定；至少两个完整候选的主要构造起点独立于用户选定意象，先为它们安排原名的其他材料，再检索选名。至少一条 A 历史拼写路线默认保留；它实际独立时可计入上述两项，另一项应从原名其他含义、同音借义或人物材料等不同来源展开。按实际形成链判断独立性，仅换语言、同义改写或为同一意象换隐喻不算独立。四类方法可以组合，无需各占一项；没有新增价值时不靠重复变体凑数，整组避免仅换名字而复用同一创作姓氏。

4. **选材并适配。** 姓与名分别推演，再按各自目标风格组合。先取较生僻的基础名形、历史异写或有参照的创作；常见规范名可以作为检索入口。历史路线必须完成“原读音 → 历史实录／类推中间形 → 目标语言姓名参照 → 完整基础名”；只在语义候选的姓上使用历史拼写，不代替独立 A 路线。按下表读取实际采用的方法，不默认全文加载所有参考。

5. **按需修饰。** 基础名已符合选材偏好后，可进一步调整音节、词尾、节奏或复合构形，参照[共享适配指引](references/target-language-name-adaptation.md)。修饰非必需；同时展示“完整基础姓名 → 完整修饰姓名”，说明保留、参照与改动，两种版本仍计一个候选。修饰形可以未被数据库收录。

6. **交付并留存。** 先给完整候选表，再给每条简短形成链和少量条目 ID／来源链接。注明姓名顺序、语言与方法，区分实录、规范名和本次创作；不要求逐字保义、所有形式都有历史记录或量化评分。按下节保存精简案例，给出文件链接。

完整姓名以外，整组可额外提供零个或一个无姓氏的**象征单人名**，不要求必有。给出时必须说明它象征什么、怎样联系原名或人物；仅省略姓氏或只凭音形好听不足以构成这一项。单人名不补足至少四个完整姓名，也不占至少两个独立完整候选的数量；未提供时省略该段。基础版与可选修饰版仍按同一候选计数。

用户只要求修改某一候选、另定数量或仅要历史写法时，按指定范围处理，不强制重新生成整组；明确只要历史转写时可停在中间形。

## 输出与留存

候选表包含：构造起点及与用户所选意象的关系、完整基础姓名及姓名顺序、可选修饰后的完整姓名、语言／风格、所保留联系和关键依据。明确标出回应项、至少两个独立来源项与默认历史项；历史中间形另列于对应形成链。按实际候选数量追加表格行和形成链，不预置四项终点；可选象征单人名单独列出其象征含义。

每次命名完成后，用[精简案例模板](assets/case-template.md)写入项目本地 data/examples/。文件名取原名 Hepburn 读音的小写形式、空白改连字符，附用户本地时间 YYYYMMDD-HHmmss；本项目默认时区 Asia/Shanghai。例如 komeiji-koishi-20261111-194200.md。初步交流尚未形成结果时不保存成已完成案例。

记录实际提供的意象方向（或用户已明确、未重复询问的情况）、本次约束、skill 版本、实际候选数量、各条构造起点及与用户意象的关系、形成链与少量依据；如提供单人名，记录其象征含义。模板的候选行与形成链按实际数量展开，可选单人名段落可整段省略，不保留未填写的占位内容。只有用户指定才记为最终采用；认可整组不等于选定某个姓名。后续反馈追加到同一次案例，新创作另建文件；明确指出该次可选修饰是否采用。默认不保存全量工具返回或建立案例索引，精选案例另行整理入仓库。

名称创作与项目验收分别处理；日常命名不触发数据库重建、验收脚本或 GitHub 发布。
